# mncs-math

Machine-native scientific mathematics for MNCS, written in MNCS
Language: exact integer/rational/fixed-point tiers, concrete-shape
linear algebra (through 6x6), index-map tensors plus data kernels,
interval arithmetic, dual-number autodiff with exact Halley steps,
exact numerical methods, lattice optimization, exact statistics
with covariance, reproducible randomness, and a binary64 float
tier — every expectation derived by an independent oracle and
frozen into self-contained corpora.

## Layout

- `src/math/` — 26 modules (`error`, `internal`, `scalar`,
  `rational`, `bigint`, `fixed`, `complex`, `vector`, `matrix`,
  `linalg`, `tensor`, `interval`, `autodiff`, `deterministic`,
  `statistics`, `numerical`, `optimize`, plus the wave-2 science
  push: `float`, `poly`, `modular`, `ntt`, `sparse`, `linalg5`,
  `tdata`, `bigintx`, `ode`).
- `tests/tables/` — authored oracle tables (the independent
  expectations); `tests/corpora/` — frozen execution corpora
  generated by `tools/mkcorpus.py` (plus `*-traps` corpora pinning
  deterministic `runtime_failure`).
- `tools/oracle_*.py` — independent exact-arithmetic oracles that
  emit the tables; `tools/gen_examples.py` — example corpora.
- `examples/` — runnable end-to-end programs with frozen corpora
  (`scripts/examples.sh`).
- `repro/` — minimal language/backend pressure reproducers, each
  with `case.mncs`, `corpus.json`, `README.md`, and `expected.md`.
- `rfcs/` — accepted design records; `docs/` — capability notes,
  `docs/error-model.md`, `docs/performance.md`,
  `docs/generics.md` (measured per-size copy costs), and
  `docs/language-pressure.md` (the evidence-backed roadmap for the
  next language run).
- `scripts/check.sh <module>` — source-study + both interpreted
  backends + traps; `scripts/conformance.sh` — the full
  five-backend matrix over all modules, examples, and trap
  corpora; `scripts/bench.sh` — per-case step counts.

## Verify

```bash
for m in error scalar rational internal bigint fixed complex vector \
         matrix linalg tensor interval autodiff deterministic \
         statistics numerical optimize float poly modular ntt \
         sparse linalg5 tdata bigintx ode; do
  bash scripts/check.sh "$m" || break
done
bash scripts/examples.sh
bash scripts/conformance.sh --out target/conformance
```

Language profiles 0.6–0.12 per module (float tier needs 0.12);
toolchain `mncs-language` is external and read-only. Only this
repository is modified by this work.
